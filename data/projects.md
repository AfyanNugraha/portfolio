## Body Mass Index (BMI) & Distance Monitoring App 
Kategori: Mobile Application
Gambar: /projects/PBTG.jpeg
Deskripsi: Aplikasi interaktif yang menghitung Indeks Massa Tubuh (BMI) berdasarkan tinggi dan berat badan. Dirancang untuk memberikan cara sederhana bagi pengguna untuk memeriksa BMI mereka dan memahami kategori massa tubuh mereka. Sekaligus untuk memantau dan menghitung jarak, membantu pengguna melacak pergerakan mereka dan melihat pengukuran jarak dengan cara yang sederhana dan praktis dalam satu halaman.
- Expo (React Native) + Expo Go
- Node.js
- VS Code
- OpenStreetMap + Leaflet

## Goods Inventory System Application
Kategori: Mobile Application
Gambar: /projects/PPB.jpeg
